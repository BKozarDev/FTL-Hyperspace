# FTL Co-op: дизайн

Кооп «флот»: у каждого игрока свой корабль, вместе против общего врага.
Каждый игрок запускает свою копию FTL; хост ведёт общее состояние (врага, карту, события).

## Правила

1. **Лобби в ангаре.** Хост создаёт игру на экране выбора корабля, второй игрок
   присоединяется там же. Каждый выбирает свой корабль, хост запускает забег для всех
   с одним seed.
2. **Корабль союзника виден снаружи**, как вражеский корабль без сенсоров: корпус, щиты,
   попадания, выстрелы. Внутренности (экипаж, комнаты, системы) не видны.
   Размещение: уменьшенный примерно вдвое под своим кораблём; когда врага нет —
   на месте вражеского окна.
3. **Смерть.** Если корабль игрока уничтожен, забег не заканчивается: погибший
   наблюдает, выживший продолжает. Забег кончается, только когда погибли все.
4. **Воскрешение** покупает выживший за свой scrap:
   - доступно после каждой победы в бою (враг уничтожен или сдался) и в любом магазине;
   - если денег не хватает, можно в следующий раз — после следующей победы или в магазине;
   - цена растёт с сектором: 40 + 15 × номер сектора (1-й сектор: 55, 8-й: 160);
   - воскрешённый корабль получает половину корпуса; системы и выживший экипаж —
     как были в момент гибели, погибший экипаж не возвращается.
5. **События на маяках** выбирает хост: у остальных окно события само принимает
   выбор хоста и закрывается. (Раньше планировалось голосование — заменено по решению автора.)
8. **Настройки лобби** (сложность, Advanced Edition и подобные) задаёт хост;
   у остальных эти кнопки заблокированы и повторяют выбор хоста.
6. Scrap, топливо, ракеты, дроны — у каждого свои.
7. **Цели врага.** Враг стреляет по живым игрокам случайно, переключаясь между ними
   (то по одному, то по другому). Цель для каждого выстрела выбирает хост.

## Вехи

1. Лобби в ангаре: хост/подключение из меню, обмен выбранными кораблями, общий старт с одним seed.
2. Общий забег: синхронные прыжки, общая карта, выбор в событиях за хостом, общая пауза.
3. Корабль союзника снаружи: корпус, щиты, прочность.
4. Общий враг: состояние врага у всех одно, попадания каждого бьют по нему,
   враг стреляет в выбранного хостом игрока; выстрелы и попадания видны на корабле союзника.
5. Смерть, наблюдение и воскрешение за scrap.

## Сделано

- Сетевой слой на ENet: COOP_HOST / COOP_JOIN / COOP_PING / COOP_STATUS / COOP_LEAVE
  в консоли (`\`), проверка версии протокола.
- Веха 1, лобби (`CoopLobby.cpp`): кнопка CO-OP в ангаре, окно с HOST / JOIN по IP,
  список игроков и их кораблей, START только у хоста, общий seed через поле seed Hyperspace.
  Забег с seed считается «seeded run», поэтому достижения и разблокировки в нём выключены.
- Веха 2, часть 1 (`CoopRun.cpp`): прыжки ведёт хост — цель из `StarMap::GetNewLocation`
  у хоста рассылается (маяк по координатам или сектор по индексу из `SelectNewSector`),
  клиент прыгает как при принудительном прыжке флагмана; JUMP и выбор сектора у клиента
  блокируются. Общая пауза по `CommandGui::bPaused` (хост пересылает паузу клиента остальным).
  Перезапуск: `WorldManager::Restart` у хоста рассылает новый seed, клиент вызывает Restart.
  Seed забега задаётся через Lua-событие Hyperspace `GET_RUN_SEED` (`Run::ForceNextSeed`).
- Веха 2, часть 2: выбор в окне события (`CommandGui::choiceBox`) у хоста рассылается
  (номер + текст варианта), клиент применяет его по тексту, иначе по номеру, по очереди
  для цепочек окон; свой выбор у клиента заблокирован. Сложность (`*Global::difficulty`)
  и Advanced Edition (`Settings::bDlcEnabled`) хоста применяются у клиентов в ангаре
  и ещё раз при старте.
